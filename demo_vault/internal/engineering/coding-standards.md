# Coding Standards

Small PRs, honest names, tests that fail for the right reason. We optimise for
the reader, not the writer.

## Reviews

Every change gets one review. Review within one working day or say when you
can. "Looks good" without reading it is worse than no review.

## AI-assisted changes

AI-generated changes follow the same bar: the author owns the diff, the tests
prove the behaviour, and the eval gate must pass before merge.
