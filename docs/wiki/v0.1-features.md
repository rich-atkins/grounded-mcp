# grounded-mcp v0.1 — what it does, and how to read it

grounded-mcp is an MCP server for markdown knowledge vaults (Obsidian works as-is) that ships with its own eval suite. The differentiator is not the plumbing: it is that the server's trust properties are CI-gated numbers rather than claims.

## The three guardrails

**Citations.** Every content-bearing response carries a stable citation id (`path#heading` plus line spans). Nothing is returned that cannot be quoted with provenance.

**Abstention.** Search refuses to dress weak matches up as answers. The bar is a double gate, tuned by measurement: BM25 score alone could not separate true answers from confident-looking misses (the ranges overlap), so a term-coverage gate joins it. Below the bar, the response is a structured `abstained: true` with the scores that failed, never a guess.

**Entitlements.** Declarative allow/deny profiles, enforced at INDEX level: content a profile cannot see is never indexed for it, so it cannot leak through rankings, snippets or result counts. A denied note and a nonexistent note return identical responses (the server is not an existence oracle). A redaction guard refuses to serve notes containing secret-shaped strings regardless of entitlements.

## Tools

| Tool | What it does |
|---|---|
| `search(query, k)` | BM25 over titles/headings/tags/body; cited hits or explicit abstention |
| `read_note(citation, section_only)` | a note or single section by citation id |
| `backlinks(path)` | wikilink graph, within your entitlements |
| `browse(prefix, tag)` | list visible notes |

Read-only by design: a server that can quote your vault but never rewrite it is a trust feature.

## The eval suite (the point of the project)

Four CI-gated families against a committed synthetic demo vault (ACME Ltd, three zones): retrieval quality (hit@1 / recall@5 / MRR), abstention correctness, entitlement leakage (hard zero, checked unthresholded), and redaction (seeded fake credentials must never serve). Weaken the abstention gates via env and the build fails with exit 1 — run `GROUNDED_MIN_SCORE=0 GROUNDED_MIN_COVERAGE=0 python evals/run_evals.py` to watch.

## Honest boundaries

Over stdio, client and server run as the same user, so entitlement profiles demonstrate the deployment pattern rather than defend against a hostile peer (real per-client enforcement is the v0.2 HTTP work). Retrieval is deliberately plain BM25: a measurable baseline that hybrid semantic retrieval must beat with a published delta, or it does not land. The redaction patterns catch key-shaped strings, not every secret.
